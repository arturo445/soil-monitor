# Soil Monitor — dashboard

Modo: Operate. Uso: consulta rápida desde computador o móvil en una red local.

Fondo cálido #f5f4ed, superficie #ffffff, texto #20362e, cabecera bosque #173e32. Tipografía de sistema para lectura offline, números tabulares. Acento vegetal #d6e8b1. Estados independientes: seco #ae3027, necesita agua #855900, adecuado #256148, exceso #175f9b.

Una única área de lectura junto a la cadena de conexión Sensor / Uno / ESP / navegador; gráfico debajo. Sin navegación ficticia, decoración fotográfica ni métricas inventadas. Escala ADC explícita, nunca porcentaje. Bordes sutiles, radios 16px, separación de secciones 32px; columna única bajo 760px. Animación de entrada discreta y respetuosa de reduced-motion.

Carga, configuración ausente, HTTP inaccesible, enlace serial perdido y recuperación son estados de primera clase. Un dato anterior permanece solo en el historial, nunca en la lectura actual. Los controles usan elementos nativos y la red local no necesita recursos externos.
